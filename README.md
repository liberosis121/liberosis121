**My roles:** Project Leader, UI/UX Designer, DevOps, and Full-stack Developer  
**Technologies:** React 19, TypeScript, Tailwind CSS, Node.js, Express.js, Supabase, PostgreSQL  

Key contributions:

- Integrated role-based authentication flows and router guards using Supabase Auth and React Router v7
